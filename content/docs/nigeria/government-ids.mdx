## Explain the request

List the identity numbers or documents your service accepts before people start. Distinguish a number from a document or photograph. Explain any alternatives and how someone without an accepted ID can get help.

State the purpose of the check and the information used. Verify the current product requirement and legal basis with the responsible team. Do not copy a monetary threshold from another service.

<CopyExample label="Identity check template — replace placeholders before use">
We need to verify your identity to [specific purpose]. We use [required information] to [specific check]. [Explain how the information is used and link to the relevant privacy information].
</CopyExample>

## Help people find their BVN

Spell out Bank Verification Number (BVN) on first use. Where retrieval instructions are useful, keep the dialling code in literal code formatting.

<CopyExample label="BVN retrieval hint">
Dial `*565*0#` from the phone number registered for your BVN to check yours. A ₦20 service fee applies.
</CopyExample>

[NIBSS documents the code, registered-number requirement and fee](https://nibss-plc.com.ng/ussd-validation-services/), checked on 30 October 2026. Recheck before publishing these instructions in a product. Provide a support route for people who cannot use the registered number. Check any other ID retrieval instructions with the issuing authority; do not assume this code retrieves a NIN.

## When verification fails

Distinguish a mismatch from an unavailable verification service. Say which detail needs attention only when the system can establish that reliably. Avoid exposing another person’s record.

Do not assume a bank statement and a BVN record always contain the same name. Do not require a person to change an identity record until the responsible provider has confirmed what needs correcting.

<CopyExample label="Illustrative BVN name mismatch — use only for a confirmed mismatch">
The name you entered does not match the name returned by the BVN check.

Check the name you entered and try again. If it still does not match, ask your bank to help you check your BVN record.
</CopyExample>

Offer the service’s verified support route when self-service cannot resolve the problem. Test the journey with people whose names contain multiple parts, diacritics, hyphens or a single name.
