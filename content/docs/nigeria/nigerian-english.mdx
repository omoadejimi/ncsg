## Use familiar terms with context

Use terms familiar to your audience. “Airtime” is a useful starting point for phone credit in Nigerian services. Test it with the people who will use your product rather than assuming everyone understands it.

Familiarity can vary by region, language, age and experience with a service. Explain an unfamiliar term where it first matters, including for Nigerian audiences.

## Suggested vocabulary

These are editorial starting points, not findings from a published NCSG comprehension study.

| Term | Suggested wording | Context and alternatives |
| --- | --- | --- |
| airtime | Buy airtime | Use for phone credit. Explain it if your audience needs help. |
| recharge | Recharge your phone | Use for adding airtime. “Add money” may be clearer for a wallet. Test the action label. |
| data | Buy a data bundle | Use “data bundle” or “data plan” when distinguishing internet access from personal data. |
| POS | POS terminal or POS agent | Name the device or the agent service explicitly. POS alone can be ambiguous. |
| transfer | Send money | “Transfer” can name a transaction type. State where the money is going when it matters. |
| BVN, NIN | Bank Verification Number (BVN); National Identification Number (NIN) | Spell out each on first use in a journey, then use the abbreviation. See [Government IDs](/docs/nigeria/government-ids). |
| network | Mobile network or connection | Name the mobile operator when relevant. Distinguish a lost internet connection from an unavailable bank service. |

## Name the person receiving money

Use “recipient” or “person you’re paying” in general payment journeys. “Beneficiary” may be necessary in a legal document or an established specialist flow; explain its meaning there. Use the same term in buttons, messages and help content.

## Words to use with care

- Replace “do the needful”, “kindly revert” and similar phrases with a specific action. See [Plain language](/docs/foundations/plain-language).
- Use informal expressions only where they fit the audience and situation. Avoid jokes in payment failures, security warnings and other sensitive messages.
- Keep the meaning precise: “electricity” is clearer than “light” in a bill or service-status message.

## Spelling

Use British spelling as NCSG’s editorial convention: **colour, organise, centre, licence** (noun), **license** (verb) and **cheque**. Preserve the official spelling of names and products.

## Treat Nigerian Pidgin as a language

Do not create a Pidgin version by adding a few expressions to English. Use translators and reviewers familiar with the intended audience. See [Translation principles](/docs/multilingual/translation-principles).
