## The naira symbol

Use **₦** directly before the amount with no space: **₦5,000**. 

If a system cannot render ₦ reliably, use **NGN 5,000** — never a bare "N", which is ambiguous in running text.

## Formatting amounts

- Always use thousands separators: **₦1,500,000**, never ₦1500000.
- When kobo matters (interest, exchange rates, unit pricing), show two decimal places consistently: **₦20.50**.

## Words or symbols

When writing interface copy, opt for the symbol. In long-form content where an amount is spoken about rather than displayed, you can use "naira" in lowercase. For example: "a few thousand naira".

For SMS, check the encoding and segment count as well as display support. The naira symbol can change the encoding and cost. See [Notifications](/docs/patterns/notifications).

Amounts in these examples demonstrate formatting, not current fees. Use the verified fee and the product’s rounding rules in live content.
