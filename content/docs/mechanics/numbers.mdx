## Use numerals

Write numbers as figures, including 1 to 9: "You have 3 pending requests." Numerals are NCSG’s default for interface quantities. Check readability and number formatting for the language and task.

Exception: where a numeral could be misread at the start of a sentence, rewrite the sentence.

## Group long numbers

- Always separate your thousands: **1,500,000**.
- Phone numbers in Nigerian reading groups: **0803 123 4567**.
- Account numbers in pairs or as the bank presents them: **0123 4567 89**.

## USSD codes

Use literal inline code with no added spaces, and state the action. For example, `*565*0#` retrieves a BVN. Include the registered-phone requirement and fee in [Government IDs](/docs/nigeria/government-ids).

Verify each code with its operator before publication. Do not publish incomplete dialling syntax or suggest that a bank-specific code works for every account.

## Evidence and limits

**Editorial convention with an operator source.** Formatting defaults need testing in context. The linked NIBSS instructions support only the specified BVN retrieval action; they do not verify other operators’ codes. For contributions, use the [evidence record in Editorial standards](/docs/operations/editorial-standards).
